02. THE CHALLENGE

The existing portal had grown over time, which led to a fragmented experience.

  • Complex navigation structure
  • Inconsistent UI across modules
  • Information overload
  • Difficult task discovery
  • Inefficient workflows
  • Low user satisfaction

03. USERS

01. PROJECT OVERVIEW

Insight Global ERP is an enterprise platform used by employees across departments including HR, Admin, Operations, Testing, and Management. The existing system was outdated, inconsistent, and difficult to navigate.

The goal of this project was to redesign the platform experience and introduce new capabilities that align with evolving business needs.

04. RESEARCH

Methods

Stakeholder Interviews

Employee Interviews

Workflow Analysis

Competitor Benchmarking

Key Findings

  • Fragmented experience across modules
  • Inconsistent patterns and interactions
  • Excessive cognitive load
  • Important features not easily accessible
  • Multiple steps for simple tasks

05. CONSTRAINTS

  • Existing technical architecture
  • Legacy workflows
  • Business requirements
  • Data security policies
  • Limited implementation timeline
  • Scalability and future growth

06. MY ROLE

  • Conducted user & stakeholder interviews
  • Defined information architecture and user flows
  • Created wireframes, prototypes and UI designs
  • Collaborated with developers and product team
  • Ensured usability, accessibility and consistency

07. DESIGN GOALS

Reduce Complexity

Simplify information architecture and workflows.

Improve Discoverability

Make important features easy to find and access.

Increase Efficiency

Reduce the number of steps and time to complete tasks.

Improve Consistency

Create a unified UI system with reusable components.
